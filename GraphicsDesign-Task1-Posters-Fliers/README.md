# 🎨 Task 1 – Posters & Fliers

## 📌 Objective

Design a set of at least **two digital posters/fliers** for a real or fictional event, product launch, or awareness campaign while applying modern graphic design principles.

---

# 📝 Project Overview

This project was created as part of the **Oasis Infobyte Graphics Design Internship (OIBSIP)**.

Two promotional posters were designed with a focus on visual hierarchy, typography, colour consistency, and engaging layouts. Each design includes custom graphic elements and a clear call-to-action to effectively communicate the intended message.

---

# 🎯 Design Theme

- Poster 1: AI & Technology Conference
- Poster 2: Cyber Security Awareness Campaign

# 📄 Design Rationale

The posters were designed to deliver information in a visually appealing and easy-to-understand format. A limited colour palette, strong typography, and custom graphic elements were used to create a clean and professional design while maintaining visual consistency. The layouts were carefully structured to guide the viewer's attention from the headline to the call-to-action.
