# 📊 Task 4 – Infographic Design

## 📌 Objective

Create a visually engaging infographic that presents useful information in a clear, structured, and easy-to-understand format using icons, illustrations, and data visualization.

---

# 📖 Project Title

## 10 Cyber Security Tips to Stay Safe Online

---

## 📄 Project Description

This infographic provides ten essential cybersecurity tips to help users protect their digital identity and stay safe online. It combines modern design principles with icons, visual hierarchy, and informative statistics to make cybersecurity awareness engaging and easy to understand.

The design follows a clean vertical layout with a consistent blue and purple color palette, making it suitable for both digital sharing and educational purposes.

---

## ✨ Features

- Clear and informative title
- 10 cybersecurity safety tips
- Modern infographic layout
- Custom icons and illustrations
- Three cybersecurity statistics
- Trusted reference sources
- Professional typography
- High-resolution export

## 📋 Information Included

### Cyber Security Tips

1. Use Strong Passwords
2. Enable Two-Factor Authentication
3. Beware of Phishing Emails
4. Keep Software Updated
5. Backup Important Data
6. Use Secure Networks
7. Use Reliable Security Software
8. Protect Personal Information
9. Be Careful with Online Payments
10. Stay Informed & Stay Alert

- **80%** of data breaches involve weak or stolen passwords.

## 📝 Design Rationale

The infographic is designed using a clean and structured layout that guides readers through each cybersecurity tip in a logical order. Blue and purple colors were selected to represent trust, security, and technology. Icons and statistics improve readability, while consistent typography and spacing enhance the overall user experience.
