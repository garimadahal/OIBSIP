# 📖 Project Description

This project presents a professional multi-page brochure designed for **PixelCraft**, a fictional creative design agency. The brochure showcases the company's services, portfolio, brand identity, and contact information using a clean, modern, and visually engaging layout.

The design emphasizes readability, consistent branding, balanced whitespace, and professional typography while following standard print design principles.

# 📝 Design Rationale

The brochure was designed to present PixelCraft's brand identity in a clean and professional manner. A consistent purple and blue color palette reinforces the brand's creative and modern personality. The layout uses grids, generous whitespace, and clear typography to improve readability and guide users naturally through the content. High-quality visuals and organized sections ensure an engaging and professional presentation suitable for both digital viewing and print.
